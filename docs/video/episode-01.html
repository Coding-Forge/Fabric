Choose an execution host

Start locally. Choose production deliberately.

Local PoC

Native Windows or Linux. Optional WSL2: Windows desktop, Linux tooling.

Function App

Hosted timer-based collector execution, with environment-specific configuration.

Collector notebook

Python collection in a notebook runtime, coordinated by an approved pipeline.

A different host does not grant different API permissions.

Make the handoff explicit

Collection output must reach Lakehouse Files.

Collector destination

Local folder, Blob / ADLS or a configured Lakehouse path.

Analytics input

Existing files under the selected raw root in the attached default Lakehouse.

Validate the copy, shortcut or other chosen handoff separately. This is not an automatic transfer supplied by Monitor.

Authorization boundaries

Admin visibility is not universal access.

API authorization

Endpoint-specific tenant settings, application permissions and consent.

Resource access

Item, connection, dataset, gateway or deployment-pipeline permissions.

Storage access

Separate authorization to read raw evidence and write intended outputs.

Execution identity

Validate the identity actually used by manual and scheduled runs.

Scope before enablement

Know what each feature can observe.

Job history

Configured supported items. Actual job-history access. Recent observations, not an unlimited archive.

Connections

Caller-visible connections. Connection permission. Not tenant-complete discovery.

Definitions

Tenant-discovered notebooks and data pipelines. Item read/write access. Sensitive exported source.

See the configuration reference for all API families, exact permissions, collection boundaries and limitations.

Interpret evidence honestly

Execution success is not collection completeness.

Missing is not zero

Uncollected or failed evidence remains unknown.

History is not current state

Do not add snapshots together as current inventory.

Metadata is sensitive

Protect identities, definitions and retained observations.
